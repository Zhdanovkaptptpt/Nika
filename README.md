Движок расчёта скидок для маркетплейса «Штучки-Дрючки» на Python с паттернами Стратегия, Фабрика и Синглтон. Семь типов скидок: процентная, фиксированная, 3 по цене 2, промокод, лояльность, первый заказ, бесплатная доставка. Порядок применения: 3 по 2, затем выбор максимума между процентной скидкой и процентным промокодом (при равенстве — промокод), потом лояльность и первый заказ, фиксированные скидки и промокоды, в конце бесплатная доставка.
Округление банковское (half to even) после каждой скидки. Промокод одноразовый в заказе, срок включителен. 
Запуск: python main.py, в меню 1 — тесты (12 штук), 2 — демо-расчёт с выбором по цифрам, 0 — выход.
Тесты отдельно: python -m unittest tests.py. Для новой скидки — наследовать IDiscount и зарегистрировать в Registry, движок трогать не нужно.
