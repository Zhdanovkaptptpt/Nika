Проект реализует движок расчёта скидок на Python с использованием паттернов Стратегия, Фабрика и Синглтон.
Схема классов. Абстрактный класс IDiscount задаёт контракт для всех скидок через свойства name, stage и метод apply. От него наследуются семь стратегий: PercentDiscount, FixedDiscount, ThreeForTwoDiscount, PromoCodeDiscount, LoyaltyDiscount, FirstOrderDiscount, FreeDeliveryDiscount. Класс DiscountRegistry реализует Синглтон и Фабрику одновременно: хранит реестр создателей стратегий и создаёт объекты скидок по типу из конфигурации. PricingEngine работает только с абстракцией IDiscount, не зная о конкретных классах скидок. Модели данных: Product, CartItem, Customer, Order, DiscountContext, AppliedDiscount, PricingResult.
Порядок применения скидок. Сначала 3 по цене 2, затем процентные скидки с выбором максимума между обычной и процентным промокодом, затем лояльность и первый заказ, затем фиксированные скидки, в конце бесплатная доставка. Каждая следующая скидка считается от уже уменьшенной суммы.
Правила округления. Все денежные значения в типе Decimal, округление до копеек банковским способом round half to even сразу после вычисления каждой скидки.
Трактовка промокодов. Промокод одноразовый в рамках одного заказа. Процентный промокод конкурирует с обычной процентной скидкой, выбирается большая выгода, при равенстве промокод. Фиксированный промокод применяется на этапе фиксированных скидок. Неизвестный или просроченный код не применяется. Срок промокода включителен.
Инструкция запуска. Команда python SKIDKI.py, в меню выбрать 1 для демонстрации или 2 для запуска тестов
